# Kernel_CodeSexer

## 커널아카데미 코드섹서 모임

### Branch
1. 각자의 이름으로 브랜치 생성
   - ex) MinsooLee
2. 폴더 이름은 각자 알아서 정하기
   - 대신, 공유가 목표라 다른 사람들도 알아볼 수 있게!
3. 푸시 할 때 git push origin "브랜치명"
   - 이 때 Pull Request 하라고 뜨는데, 혹시 하는 방법 모르시면 슬랙으로 문의주세용
4. 각자 브랜치에서 푸시 후 저에게 말씀해주세용
   풀 리퀘스트 해야합니다
   반영하고 나서 바로 알려드릴게요!
